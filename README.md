# Найди баг — Python + Ollama

Простой школьный веб-проект: 15 задач с ошибками, три уровня сложности, подсказки и разбор кода локальной моделью. Без дополнительного оформления, регистрации и файлов CMD.

## Запуск

Установи Python 3.10+ и [Ollama](https://ollama.com/download), открой Ollama. В терминале в папке проекта выполни:

```text
python -m pip install -r requirements.txt
ollama pull qwen2.5:3b
python -m streamlit run app.py --server.address 127.0.0.1
```

Модель скачивается один раз (около 1,9 ГБ). Для повторного запуска достаточно открыть Ollama и выполнить последнюю команду. Если нет соединения, запусти `ollama serve` в отдельном терминале. Если сервер уже работает, второй раз запускать его не нужно.

После установки библиотек и загрузки модели запросы к локальной Ollama работают без интернета. Скорость ответа зависит от компьютера.

## Использование

Выбери сложность и задание. Исправь код в поле «Твой код». «Подсказка» даёт намёк по текущему коду, «Разобрать решение» просит модель объяснить, соответствует ли он условию.

Изменения кода сохраняются при переключении заданий и уровней в текущем сеансе. При обновлении страницы или перезапуске сервера они могут сброситься. Решения на диск не записываются.

## Уровни

| Уровень | Пять задач |
| --- | --- |
| Лёгкий | Чётность, сумма от 1 до n, положительные числа, разворот строки, квадрат числа |
| Средний | Максимум, среднее, факториал, поиск семёрки, английские гласные |
| Сложный | Бинарный поиск, простые числа, скобки, второй различный максимум, слияние списков |

## Файлы

- `app.py` — интерфейс: выбор сложности и задачи, поле кода, кнопки и сообщения об ошибках.
- `tasks.py` — 15 задач по уровням. У каждой есть уникальный `id`, название `title`, условие `text` и код с ошибкой `code`.
- `llm.py` — функция `ask_ollama()`, отправляющая условие, уровень и текущий код модели. Здесь же переменная `MODEL`: можно выбрать другую модель из `ollama list`.
- `requirements.txt` — две библиотеки для установки.
- `README.md` — эта инструкция.

Чтобы добавить задание, допиши словарь в нужный уровень в `tasks.py`. Придумай уникальный `id`. Интерфейс подхватит новую задачу автоматически. Новый уровень можно добавить отдельным ключом в словарь `TASKS`.

## Что делает LLM

Приложение обращается к Ollama через Python-библиотеку `ollama` по адресу `http://localhost:11434`. Код ученика не исполняется: оценку даёт модель. Автоматических тестов решений и баллов нет. Модель может ошибиться, поэтому проверяй объяснения на примерах и граничных случаях.

Документация: [Streamlit](https://docs.streamlit.io/), [Ollama для Python](https://github.com/ollama/ollama-python), [Qwen2.5 3B](https://ollama.com/library/qwen2.5:3b).
